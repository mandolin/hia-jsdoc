# HIA JSDoc Fixtures

Fixtures cover preset output, runner config, published JPHS/JTH bridge wiring and integration artifacts.

- `basic/src/math.js` is the source fixture.
- `basic/generated/jsdoc.conf.json` is generated by `@hia-doc/jsdoc-runner`.
- `basic/out/` contains real JSDoc HTML, theme metadata and `hia-integration.json`.

Regenerate fixture output with:

```sh
npm run build:fixtures
```
